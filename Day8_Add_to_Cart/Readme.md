

# 🛒 Add to Cart Website

A simple and interactive **Add to Cart** shopping page built using **HTML**, **CSS**, and **JavaScript**. The website showcases **6 products** with the functionality to **add them to a sidebar cart**, **track quantities**, and **calculate the total price** in real-time.

## 🚀 Features

* 🧺 Display of 6 individual products
* ➕ **Add to Cart** button for each item
* 📦 Products added appear in the **sidebar cart**
* 🔢 **Product quantity counter** increases with each addition
* 💰 **Real-time total price** updates based on selected products
* 📱 Fully responsive design
* 🧠 Powered by **Vanilla JavaScript** – no frameworks

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)

## 📁 How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/add-to-cart-website.git
   ```
2. Open the `index.html` file in any modern web browser.
3. Click on **"Add to Cart"** for any product to add it to the sidebar.
4. Watch the cart update with product name, quantity, and total price.
