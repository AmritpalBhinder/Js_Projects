

## ⏱️ Stopwatch Web App

A simple yet functional **Stopwatch** built using **HTML**, **CSS**, and **JavaScript**. The app allows you to **start**, **stop**, **resume**, and **reset** the timer using intuitive **icon buttons**.

---

### 🚀 Features

- ▶️ **Start Button** – Begins or resumes the timer  
- ⏸️ **Stop Button** – Pauses the timer  
- 🔄 **Reset Button** – Resets timer back to `00:00:00`  
- ⏱️ **Accurate time tracking** using JavaScript intervals  
- 💡 Clean and responsive UI

### 💼 How It Works

1. **Start Icon**: Starts or resumes the stopwatch.
2. **Stop Icon**: Pauses the current time.
3. **Reset Icon**: Resets the stopwatch to zero.

Time continues from where it stopped unless reset.
