

# 🌦️ India Weather App

A responsive web application built with **HTML**, **CSS**, and **JavaScript** that displays real-time **weather information** for **all cities in India**. It fetches live data using a **Weather API** and shows the **temperature**, **humidity**, and **air speed** (wind speed) for the selected city.

## 🚀 Features

* 🌇 Search weather by any **Indian city name**
* 🌡️ Displays **temperature**, **humidity**, and **wind speed**
* 🔄 Real-time data fetched using **Weather API**
* 📱 Responsive design – works on all devices
* 🎨 Simple and clean UI with CSS

## 🔧 Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)
* OpenWeatherMap API (or the API you used)
