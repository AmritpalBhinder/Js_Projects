

## 🎯 10 MCQ Quiz App

A simple and interactive **10-question multiple choice quiz** built using **HTML**, **CSS**, and **JavaScript**. Users can select their answer and click the **"Next"** button to move to the next question. At the end of the quiz, the total score is displayed.

---

### 🚀 Features

- 📝 10 Multiple Choice Questions  
- ✅ Instant answer selection and progression  
- 🎯 Final score display after last question  
- 💡 Built using only HTML, CSS, and JavaScript  
- 🧠 Simple UI for a smooth quiz experience

### 🔧 How It Works

1. Each question is displayed one at a time.
2. The user selects one of the given options.
3. On clicking **"Next"**, the next question appears.
4. After the 10th question, the final score is shown.
